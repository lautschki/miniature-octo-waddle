## Verwendete Git-Befehle

```bash

git add datei.txt           # Datei in die Staging Area legen
git add .                   # alle Änderungen in die Staging Area legen
git commit -m "Nachricht"   # Commit mit Nachricht erstellen
git push                    # Änderungen zu GitHub hochladen
```
